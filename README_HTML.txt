AegisForge HTML Conversion
===========================

This package contains the PHP pages converted to static HTML.
No PHP server/XAMPP is required for the converted pages.

Main page:
AegisForge_SIH26026_SIH_UI/index.html

Additional converted page:
AegisForge_SIH26026_SIH_UI/index_test.html

Nested duplicate converted page:
AegisForge_SIH26026_SIH_UI/AegisForge_SIH26026_SIH_UI/index.html

Assets (CSS, JavaScript, images and team photos) are preserved.
